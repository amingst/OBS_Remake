## Prerequisites

### Odin Lang

Need to install the Odin language following the directions from the following page and add to path
https://odin-lang.org/docs/install/

### Premake5

Needs premake5 for building the graphics library
https://premake.github.io/download

### Python3.3+

Needs python3.3 or higher to build needed files in the graphics library

## Building Project

run this from the project root

```
odin build src -out:build/app.exe -collection:libs=libs
```
